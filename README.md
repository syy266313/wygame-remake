# 反抗之战 · 重制版

**一个 2014 年 Unity 4.3 小 Demo 的 HTML5 重写。** 原项目：[bigrpg/wygame](https://github.com/bigrpg/wygame)

**在线游玩** → 启用 Pages 后访问 `https://syy266313.github.io/wygame-remake/`
**本地游玩** → 双击 `index.html`，不需要构建、不需要服务器、零依赖

---

## 这是什么

一款反乌托邦题材的网页策略游戏。你指挥一场地下运动，要把「黑铁政权」的镇压力量压到 **六比一**，才能推翻它。

核心是三条资源、五项升级、一场不断加码的军备竞赛。

原版是 Unity 4 时代的小 Demo：一张地图、三个数字、两个按钮，10 万启动资金能在两分钟内直接平推通关。这一版把玩法重做了，但保留了它的骨架——**地表随势力整片变色、6:1 的胜负线、解放区从大陆中心向外扩散**。

## 怎么玩

### 三条资源

| 资源 | 作用 | 增减方式 |
|---|---|---|
| **资金** | 唯一的购买货币 | 由追随者产出，宵禁期间打六折 |
| **追随者** | 人多 → 钱多，也是总攻的门槛 | 组织自然增长；隐蔽度低时被镇压抹掉 |
| **隐蔽度** | 0–100，决定增长系数与镇压损失 | 自然回升；事件会打掉它 |

### 胜负条件

势力占比 `share = P / (P + G)`

- `share ≥ 85.7%`（战力比 6:1）→ **胜利**
- `share ≤ 14.3%`（战力比 1:6）→ **失败**
- 什么都不做，大约 9 分钟后失败

### 五项升级

| 升级 | 效果 | 基础价 | 涨价系数 |
|---|---|---|---|
| 地下武装 | 战力基底 ×√(Lv+1)，每级还直接 +5 战力 | 60 | ×1.22 |
| 技术小组 | 战力倍率 +45%/级 | 140 | ×1.30 |
| 地下印刷 | 追随者增长系数 +0.55/级 | 90 | ×1.20 |
| 隐蔽网络 | 隐蔽恢复 +0.16/秒·级 | 160 | ×1.22 |
| 国际支援 | 资金倍率 +40%/级（需技术 Lv5 解锁） | 240 | ×1.28 |

战力公式：

```
dP/dt = 0.14 · 军队Lv · (1 + 0.55 · 科技Lv)
```

单点堆军队是线性的，科技是乘子 —— 想赢必须两条腿走路。

### 政府不是靶子

政府战力自动增长，而且**你越强它动员越狠**：

```
dG/dt = 0.30 + 5.5 · share³     (share > 78% 时再 +2.0)
```

所以 80% 之后会进入僵持段，这是刻意设计的墙。

### 随机事件（每 20–34 秒）

大搜捕、宵禁、宣传战、国际声援、工人罢工、叛徒告密、缴获军火库 —— 共 7 类，好坏各半。

### 总攻

追随者 ≥ 400 且冷却结束时可用：自身损失 30% 追随者、隐蔽度 −22，换取政府战力直接 `×0.62`。用来打破 80% 附近的僵持。

## 平衡测试

用一个无 UI 的模拟器跑了四种策略（1× 速度，把 `core.js` 直接塞进 Node 就能复现）：

| 策略 | 结果 | 用时 |
|---|---|---|
| 正常操作（补科技 / 隐蔽 / 印刷） | 通关 | **8.1 min** |
| 只买最便宜的升级 | 通关 | 7.9 min |
| 完全挂机 | 失败 | 9.2 min |
| 只爆军队不补科技 | 通关 | 16.3 min |

节奏：前 30 秒占比冲到 ~54%，2 分钟磨到 70%，最后 3 分钟在 78%–85% 之间僵持。坏策略能过，但要多花一倍时间。

## 相对原版的改动

| 原版问题 | 这一版 |
|---|---|
| 开局 10 万资金，等于 200 次升级，难度曲线不存在 | 起始 600，收入靠追随者，升级指数涨价 |
| `m_support` / `m_death` 只更新 UI，对胜负毫无影响 | 追随者决定经济与人力，隐蔽度过低会持续减员直至失败 |
| 政府科技每 3 秒固定 +1，是个静止靶子 | 政府随你的占比非线性动员，后期会反扑 |
| Unity 4 的 `GUIText` / `HitTest`，现代 Unity 打不开 | 原生 Canvas + DOM，手机浏览器直接跑 |
| 地图只有一个会变色的平面 | 147 格 hex 大陆，解放区从三块大陆中心向外扩张 |
| 没有事件、没有变速、没有存档 | 7 类随机事件、x1/x2/x4 变速、localStorage 自动存档 |

## 仓库结构

```
.
├── index.html   # 页面骨架 + 全部样式（约 7 KB）
├── core.js      # 纯逻辑：数值、微分、事件表（约 4 KB，不依赖 DOM）
└── ui.js        # 界面层：Canvas 渲染、交互、主循环、存档（约 11 KB）
```

`core.js` 里没有一行 DOM 代码，所以可以直接拿去做模拟测试：

```js
const fs = require('fs');
eval(fs.readFileSync('core.js', 'utf8'));
let s = newState();
while (!s.over) tick(s, 0.1);   // 挂机 9 分钟就会输
```

## 运行

```bash
# 最省事：双击 index.html

# 或者起个本地服务
python3 -m http.server 8000
# → http://localhost:8000
```

**开启在线游玩**：仓库 `Settings → Pages → Source` 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等一分钟。

## 技术说明

- 纯原生 JS，零依赖，无需任何构建工具
- 地图是 Canvas 里按轴向坐标生成的 hex 网格（147 格），每格带一个阈值，按进度逐格变色
- 页面宽度自适应，`dpr` 上限 2，手机上不掉帧
- 存档写在 `localStorage`，键名 `wygame_remake_v1`，每 6 秒存一次，可跨会话续玩
